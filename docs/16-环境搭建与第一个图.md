## 📦 步骤 1：创建项目并安装依赖

```bash
# 创建项目目录
mkdir my-langgraph-app
cd my-langgraph-app

# 初始化 npm 项目
npm init -y
```

在 `package.json` 中添加 `"type": "module"`，以便使用 `import` 语法：

```json
{
  "name": "my-langgraph-app",
  "type": "module",
  "dependencies": {}
}
```

安装依赖：

```bash
# LangGraph 核心 + LangChain 核心（必需）
npm install @langchain/langgraph @langchain/core

# 模型集成（本教程使用 ModelScope 平台的 OpenAI 兼容接口）
npm install @langchain/openai
```

## 🌍 步骤 3：第一个图（Hello World）

创建 `hello.js`：

```javascript
import { MessagesAnnotation, StateGraph, START, END } from "@langchain/langgraph";

// 1. 定义一个节点：就是一个普通的函数
//    接收当前状态 state，返回状态更新
const mockLlm = (state) => {
  return { messages: [{ role: "ai", content: "hello world" }] };
};

// 2. 构建图
const graph = new StateGraph(MessagesAnnotation)
  .addNode("mock_llm", mockLlm)     // 注册节点
  .addEdge(START, "mock_llm")       // 入口边：从 START 进入 mock_llm
  .addEdge("mock_llm", END)         // 出口边：mock_llm 执行完就结束
  .compile();                       // 编译！编译后才能运行

// 3. 运行图
const result = await graph.invoke({
  messages: [{ role: "user", content: "hi!" }],
});

// 4. 查看结果：最终状态
console.log(result.messages);
// [
//   HumanMessage { content: "hi!" },
//   AIMessage { content: "hello world" }
// ]
```

运行：

```bash
node hello.js
```

> 💡 **注意：** 顶层 `await` 在 ES Module 中可以直接使用，这正是我们在 `package.json` 里加 `"type": "module"` 的原因。

## 🔍 解剖这个图

### 1. `MessagesAnnotation` 是什么？

图需要一份**状态定义**（第 17 章详解）。`MessagesAnnotation` 是官方预置的状态模板，只有一个 `messages` 字段：

```javascript
// MessagesAnnotation 大致等价于：
const StateAnnotation = Annotation.Root({
  messages: Annotation({
    reducer: messagesStateReducer,  // 新消息追加到列表，而不是覆盖
    default: () => [],
  }),
});
```

因为"在状态里存一串对话消息"太常用了，官方直接打包成 `MessagesAnnotation`。

### 2. 节点返回值 = 状态更新

节点**不需要返回完整状态**，只返回"要更新的部分"：

```javascript
const mockLlm = (state) => {
  // state.messages 是当前的消息列表
  // 返回的 { messages: [...] } 会被 reducer 追加到列表末尾
  return { messages: [{ role: "ai", content: "hello world" }] };
};
```

### 3. `START` 和 `END` 是特殊节点

```javascript
.addEdge(START, "mock_llm")  // START = 图的入口（内部名 "__start__"）
.addEdge("mock_llm", END)    // END  = 图的出口（内部名 "__end__"）
```

### 4. 必须 `compile()` 才能运行

`compile()` 会检查图的结构（比如有没有孤立节点），并生成可执行的图。**忘记 compile 直接 invoke 会报错。**

## 🤖 步骤 4：接上真实的 LLM

把 mock 节点换成真实模型调用，创建 `first-llm.js`：

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { MessagesAnnotation, StateGraph, START, END } from "@langchain/langgraph";

// 创建模型（与 LangChain 教程保持一致）
const model = new ChatOpenAI({
  modelName: "MiniMax/MiniMax-M2.5",
  apiKey: process.env.MODELSCOPE_API_KEY,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});

// 节点：调用模型
async function callModel(state) {
  const response = await model.invoke(state.messages);
  // 返回消息列表，会被追加到 state.messages
  return { messages: [response] };
}

// 构建图：START → callModel → END
const graph = new StateGraph(MessagesAnnotation)
  .addNode("callModel", callModel)
  .addEdge(START, "callModel")
  .addEdge("callModel", END)
  .compile();

// 运行
const result = await graph.invoke({
  messages: [{ role: "user", content: "用一句话介绍 LangGraph" }],
});

console.log("AI 回复:", result.messages[result.messages.length - 1].content);
```

> 💡 **说明：** 传入 `{ role: "user", content: "..." }` 普通对象也可以，LangGraph 会自动转换成 LangChain 消息对象。

运行效果：

```
AI 回复: LangGraph 是一个用于构建有状态、多步骤 AI 应用的编排框架，
它把流程组织成图，支持循环、分支和人机协同。
```

## 🎨 步骤 5：可视化你的图

LangGraph 可以把图导出为 Mermaid 图片：

```javascript
import { writeFileSync } from "node:fs";

// 获取图的表示并导出 PNG
const image = await graph.getGraph().drawMermaidPng();
const arrayBuffer = await image.arrayBuffer();

writeFileSync("graph.png", new Uint8Array(arrayBuffer));
console.log("已保存 graph.png");
```

打开 `graph.png`，你会看到：

```
[START] → [callModel] → [END]
```

> 💡 **注意：** `drawMermaidPng()` 需要联网请求 Mermaid 渲染服务。也可以用 `drawMermaid()` 获取 Mermaid 文本，粘贴到支持 Mermaid 的编辑器里查看。

## 🆚 和 LangChain 链对比

同样的"一句话问答"，用链（第 08 章）和用图写出来是这样的：

```javascript
// 链的写法（LangChain 第 08 章）
const chain = prompt.pipe(model);
const result = await chain.invoke({ topic: "LangGraph" });

// 图的写法（本章）
const graph = new StateGraph(MessagesAnnotation)
  .addNode("callModel", callModel)
  .addEdge(START, "callModel")
  .addEdge("callModel", END)
  .compile();
const result = await graph.invoke({ messages: [...] });
```

图看起来啰嗦一点，但换来的是：**清晰的执行结构 + 状态管理 + 后续可以任意加循环、分支、并行**。链一旦复杂起来就会失控，图不会。

## ⚠️ 常见问题

### 1. 报错：`Cannot find module '@langchain/langgraph'`

```bash
npm install
```

### 2. 报错：图结构不完整

```
Error: Node `xxx` is not reachable
```

原因：某个节点没有和 START 所在的连通路径相连。检查 `addEdge` 是否遗漏。

### 3. 忘记 compile

```
TypeError: graph.invoke is not a function
```

`new StateGraph(...)` 返回的是构建器，必须 `.compile()` 后才有 `invoke`/`stream`。

### 4. 顶层 await 报错

```
SyntaxError: await is only valid in async functions
```

确认 `package.json` 里有 `"type": "module"`，或把代码包进 `async function main()`。

---

## 📝 本章小结

- 安装：`npm install @langchain/langgraph @langchain/core`
- 建图四步：**定义状态 → addNode → addEdge → compile**
- `START`/`END` 是特殊的入口/出口节点
- 节点是函数：接收 `state`，返回**部分更新**
- `MessagesAnnotation` 是预置的"消息列表"状态模板
- `invoke()` 运行图并返回最终状态，`getGraph().drawMermaidPng()` 可视化
