# 01-Concepts: What Is LangChain?

> 💡 **Note:** This tutorial is for LangChain.js v1.x and requires Node.js 20+

## 📖 In One Sentence

**LangChain is a JavaScript library for building large language model (LLM) applications.**

In short: it lets you build AI applications by stacking building blocks.

---

## 🤔 Why Do You Need LangChain?

### Without LangChain

```javascript
// Call the API directly
const response = await fetch('https://api.openai.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk-xxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'gpt-4',
    messages: [{ role: 'user', content: 'Hello' }]
  })
});
```

Problems:
- ❌ Every model API is different, so you have to learn each one separately
- ❌ There is no unified message format
- ❌ You have to handle streaming yourself
- ❌ You have to manage history yourself for multi-turn conversations
- ❌ You have to implement complex features (such as RAG and Agents) yourself

### With LangChain

```javascript
// A unified interface
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";

const model = new ChatOpenAI({ apiKey: "sk-xxx" });
const response = await model.invoke([new HumanMessage("Hello")]);
```

Advantages:
- ✅ Every model uses the same API
- ✅ Streaming takes a single line of code
- ✅ Built-in conversation history management
- ✅ A rich set of components (tools, chains, and Agents)

## 🎯 Typical Use Cases

| Scenario | Description | LangChain Components |
|------|------|---------------|
| Customer support | Answer user questions automatically | ChatModel + Memory |
| Document Q&A | Answer questions based on document content | RAG + VectorStore |
| Data analysis | Query data in natural language | Agent + Tools |
| Code assistant | Generate and explain code | ChatModel + OutputParser |
| Multi-step tasks | Run complex workflows automatically | Chain + Agent |

## 📦 LangChain v1.x Package Layout

```
@langchain/
├── core/           # Core abstractions (required)
├── openai/         # OpenAI-compatible models
├── anthropic/      # Anthropic models
├── community/      # Community-contributed tools and stores
└── ...
```

### Core Dependencies

```json
{
  "@langchain/core": "^1.x",      // Core abstractions (required)
  "@langchain/openai": "^1.x",    // OpenAI-compatible models
  "zod": "^4.x"                   // Schema validation (this project uses Zod v4 throughout; the official dependency allows ^3.25 || ^4)
}
```

## 📝 Chapter Summary

- LangChain = the scaffolding for LLM applications
- It provides a unified interface that hides the differences between models
- The core idea: **components** + **chain composition**
