# 02-Environment Setup: Install and Configure

## 🎯 Chapter Goals

After this chapter, you will be able to:
- ✅ Create a LangChain.js project
- ✅ Install the required dependencies
- ✅ Configure an API key
- ✅ Run your first example

---

## Step 1: Check Your Node.js Version

LangChain.js v1.x requires **Node.js 20+** (an LTS release is recommended)

```bash
node -v
# You should see v20.x.x or higher
```

If your version is too low, upgrade to Node.js 20+ (recommended)

> 💡 **Note:** LangChain 1.0+ requires Node.js 20+ because it uses newer JavaScript features.

---

## Step 2: Create a Project

```bash
# Create the project directory
mkdir my-langchain-app
cd my-langchain-app

# Initialize an npm project
npm init -y
```

---

## Step 3: Install Dependencies

```bash
# Install the core libraries
npm install @langchain/core @langchain/openai @langchain/langgraph zod
```

### About the Dependencies

| Package | Purpose | Required |
|------|------|------|
| `@langchain/core` | Core abstract classes | ✅ |
| `@langchain/openai` | OpenAI-compatible models | ✅ |
| `zod` | Schema validation | ✅ |
| `@langchain/langgraph` | Agents and workflows | ✅ (used in this tutorial) |
| `@langchain/community` | Community tools and stores | Optional |
| `dotenv` | Load environment variables | Optional |

---

## Step 4: Configure the API Key

### Option 1: Environment Variables (Recommended)

```bash
# Linux/Mac
export MODELSCOPE_API_KEY="your API key"

# Windows PowerShell
$env:MODELSCOPE_API_KEY="your API key"

# Windows CMD
set MODELSCOPE_API_KEY=your API key
```

### Option 2: Use a .env File

```bash
# Install dotenv
npm install dotenv
```

Create a `.env` file:
```
MODELSCOPE_API_KEY=your API key
```

Load it in code:
```javascript
import 'dotenv/config';
const apiKey = process.env.MODELSCOPE_API_KEY;
```

---

## Step 5: Create Your First Example

Create `hello.js`:

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";

async function main() {
  // 1. Create a model instance
  const model = new ChatOpenAI({
    model: "MiniMax/MiniMax-M2.5",
    apiKey: process.env.MODELSCOPE_API_KEY || "your API key",
    configuration: {
      baseURL: "https://api-inference.modelscope.cn/v1",
    },
  });

  // 2. Send a message
  const response = await model.invoke([
    new HumanMessage("Hello, please introduce yourself in one sentence")
  ]);

  // 3. Print the result
  console.log("AI reply:", response.content);
}

main();
```

---

## Step 6: Run It

```bash
node hello.js
```

Expected output:
```
AI reply: Hello! I am MiniMax-M2.5, an AI assistant developed by MiniMax...
```

## 🔧 Common Issues

### Issue 1: Module Not Found

```
Error: Cannot find module '@langchain/core'
```

Fix:
```bash
npm install
```

### Issue 2: Invalid API Key

```
401 Unauthorized
```

Fix: Check that the API key is correct and that you have available quota

### Issue 3: Network Timeout

```
Request timeout
```

Fix: Check your network connection, or use a regional mirror

### Issue 4: ES Module Error

```
require is not defined in ES module scope
```

Fix: Add `"type": "module"` to `package.json`, or use `import` syntax
