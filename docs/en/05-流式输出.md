# 05-Streaming: The stream Method

> 💡 **Note:** This tutorial is for LangChain.js v1.x and requires Node.js 20+

## 🎯 Chapter Goals

- ✅ Understand how streaming works
- ✅ Learn the `stream()` method
- ✅ Implement a typewriter effect

---

## 🤔 What Is Streaming?

### Non-streaming (Normal Mode)

```
User asks a question → the AI thinks for 3 seconds → all the text appears at once
```

The wait is long, and the experience is poor.

### Streaming

```
User asks a question → the AI thinks and outputs at the same time → text appears word by word
```

You see content right away, and the experience is smoother.

---

## 📦 The stream() Method

### Basic Usage

```javascript
const stream = await model.stream(messages);

for await (const chunk of stream) {
  process.stdout.write(chunk.content);
}
```

### What Is a chunk?

A `chunk` is a small piece of text the AI generates (usually a few characters):

```javascript
{
  content: "Hel",
  role: "assistant"
}
// then...
{
  content: "lo",
  role: "assistant"
}
// then...
{
  content: "! I",
  role: "assistant"
}
```

## 💡 Complete Example

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

const model = new ChatOpenAI({
  model: "MiniMax/MiniMax-M2.5",
  apiKey: process.env.MODELSCOPE_API_KEY,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});

const messages = [
  new SystemMessage("You are a friendly AI assistant."),
  new HumanMessage("Please introduce artificial intelligence in about 100 words."),
];

console.log("🤖 AI is answering:\n");

// Stream the output
const stream = await model.stream(messages);

for await (const chunk of stream) {
  process.stdout.write(chunk.content || '');
}

console.log("\n\n✅ Generation complete");
```

## 🎨 Intermediate Usage

### 1. Add a Typewriter Delay (Simulated)

```javascript
const stream = await model.stream(messages);

for await (const chunk of stream) {
  process.stdout.write(chunk.content || '');
  // Simulate a typing delay
  await new Promise(resolve => setTimeout(resolve, 50));
}
```

### 2. Collect the Full Reply

```javascript
let fullResponse = "";

const stream = await model.stream(messages);

for await (const chunk of stream) {
  fullResponse += chunk.content || '';
}

console.log("\nFull reply:", fullResponse);
```

### 3. Send to the Frontend (WebSocket Example)

```javascript
const stream = await model.stream(messages);

for await (const chunk of stream) {
  // Send it to the frontend over WebSocket
  websocket.send(JSON.stringify({
    type: 'token',
    content: chunk.content
  }));
}
```

### 4. Handle Streaming Metadata

```javascript
const stream = await model.stream(messages);

for await (const chunk of stream) {
  console.log("Current token:", chunk.content);
  console.log("Metadata:", chunk.response_metadata);
}
```

## 📋 invoke() vs stream()

| Feature | invoke() | stream() |
|------|----------|----------|
| When it returns | After it finishes | Returns immediately |
| Memory use | Loaded all at once | Loaded in chunks |
| User experience | Fair | Good |
| Use case | Short text / batch jobs | Long text / live display |

## ⚙️ stream() Parameters in Detail

```javascript
const stream = await model.stream(messages, options);

// options:
// - signal: AbortSignal - used to cancel streaming
// - streamUsage: boolean - whether to return token usage stats
```

### Example: Cancel Streaming

```javascript
const controller = new AbortController();

// Cancel after 5 seconds
setTimeout(() => controller.abort(), 5000);

try {
  const stream = await model.stream(messages, {
    signal: controller.signal
  });
  
  for await (const chunk of stream) {
    process.stdout.write(chunk.content);
  }
} catch (e) {
  if (e.name === 'AbortError') {
    console.log("\nStreaming canceled");
  }
}
```

## ⚠️ Notes

### 1. Do Not Mix Them

```javascript
// ❌ Wrong: do not call invoke() after stream()
const stream = await model.stream(messages);
const response = await model.invoke(messages);  // this calls the model again

// ✅ Correct: pick one approach
const stream = await model.stream(messages);
for await (const chunk of stream) {
  process.stdout.write(chunk.content);
}
```

### 2. Handle Empty Chunks

Some models may return an empty chunk:

```javascript
for await (const chunk of stream) {
  process.stdout.write(chunk.content || '');  // use || to avoid undefined
}
```

### 3. Error Handling

```javascript
try {
  const stream = await model.stream(messages);
  
  for await (const chunk of stream) {
    process.stdout.write(chunk.content || '');
  }
} catch (error) {
  console.error("Streaming failed:", error.message);
}
```

## 🔧 Complete Practical Example

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

async function runWithStream() {
  const model = new ChatOpenAI({
    model: "MiniMax/MiniMax-M2.5",
    apiKey: process.env.MODELSCOPE_API_KEY,
    temperature: 0.7,
    configuration: {
      baseURL: "https://api-inference.modelscope.cn/v1",
    },
  });

  const messages = [
    new SystemMessage("You are a helpful assistant."),
    new HumanMessage("Hello, please introduce yourself, using streaming."),
  ];

  try {
    console.log("🤖 AI is answering:\n");
    const stream = await model.stream(messages);
    
    for await (const chunk of stream) {
      process.stdout.write(chunk.content || '');
    }
    
    console.log("\n\n✅ Generation complete");
  } catch (error) {
    console.error("Call failed:", error.message);
  }
}

runWithStream();
```

---

## 📝 Chapter Summary

- `stream()` produces streaming output
- Use a `for await...of` loop to process each chunk
- `chunk.content` holds the text generated in the current chunk
- Best for long text and real-time display
