## 🧠 Design

```
User: "Check the weather in Sanya and book a hotel"
        │
        ▼
┌──────────────────────────────────────────────────────────┐
│  ReAct Agent (createReactAgent)                          │
│                                                          │
│  Tools: get_weather   check the weather                  │
│         search_hotel  search hotels (reports progress)   │
│         book_hotel    book a hotel (★ interrupt for      │
│                       confirmation before the order)     │
│                                                          │
│  Memory: MemorySaver + thread_id (multi-turn chat)       │
└──────────────────────────────────────────────────────────┘
        │
        ▼
  stream(messages) typewriter output to the user
        │
        ▼
book_hotel triggers interrupt → user replies "confirm/cancel" → Command({ resume }) resumes
```

## 💡 Full Code

Create `travel-agent.js`:

```javascript
import "dotenv/config";
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";
import { tool } from "@langchain/core/tools";
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { MemorySaver, interrupt, Command } from "@langchain/langgraph";
import { z } from "zod";

// ===== 1. Model =====
const model = new ChatOpenAI({
  model: "MiniMax/MiniMax-M2.5",
  apiKey: process.env.MODELSCOPE_API_KEY,
  temperature: 0,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});

// ===== 2. Tools =====

// Tool 1: check the weather (mock data)
const weatherTool = tool(
  async ({ city }) => {
    const data = {
      "Sanya": "Sunny, 28°C, good for beach activities",
      "Beijing": "Cloudy, 18°C, a big temperature swing between morning and evening",
      "Chengdu": "Light rain, 22°C, bring an umbrella",
    };
    return data[city] || `${city}: sunny, 25°C`;
  },
  {
    name: "get_weather",
    description: "Look up the weather in a city, to decide whether it is a good time to travel",
    schema: z.object({ city: z.string().describe("City name") }),
  }
);

// Tool 2: search hotels (report progress with writer)
const searchHotelTool = tool(
  async ({ city }, config) => {
    // The second argument, config, has writer, which can send progress into the stream
    config?.writer?.({ type: "progress", message: `Searching hotels in ${city}...` });
    await new Promise((r) => setTimeout(r, 500));  // simulate network latency
    config?.writer?.({ type: "progress", message: "Price comparison complete" });

    return `Recommended hotels in ${city}:\n` +
      `1. Seaview Bay Hotel - 680 CNY/night (500 meters from the beach)\n` +
      `2. Comfort Express Hotel - 320 CNY/night (downtown)`;
  },
  {
    name: "search_hotel",
    description: "Look up recommended hotels and prices in a given city",
    schema: z.object({
      city: z.string().describe("City name"),
    }),
  }
);

// Tool 3: book a hotel (★ human confirmation before the order)
const bookHotelTool = tool(
  async ({ hotel, nights }) => {
    // Pause execution and wait for a human. Do not put side effects before interrupt!
    const decision = interrupt({
      action: "book_hotel",
      hotel,
      nights,
      message: `Confirm booking ${hotel} for ${nights} nights?`,
    });

    // After resume, decision is the user's confirmation
    if (decision?.approved) {
      return `Booking confirmed! ${hotel} for ${nights} nights, confirmation number TR-2026-8899`;
    }
    return "The user canceled the booking";
  },
  {
    name: "book_hotel",
    description: "Book a hotel. Requires the hotel name and the number of nights (the user is asked to confirm before booking)",
    schema: z.object({
      hotel: z.string().describe("Hotel name"),
      nights: z.number().describe("Number of nights"),
    }),
  }
);

// ===== 3. Create an agent with memory =====
const agent = createReactAgent({
  llm: model,
  tools: [weatherTool, searchHotelTool, bookHotelTool],
  prompt: "You are a professional travel concierge. Help the user check the weather and recommend hotels. Any action that spends money must call a tool so the user can confirm first.",
  checkpointSaver: new MemorySaver(),   // multi-turn conversation memory
});

// ===== 4. Wrap one "conversation turn": streaming output + interrupt handling =====
async function chat(threadId, userMessage) {
  const config = { configurable: { thread_id: threadId } };

  // Subscribe to the token stream and progress reports at the same time
  const stream = await agent.stream(
    { messages: [new HumanMessage(userMessage)] },
    { streamMode: ["messages", "custom"], ...config }
  );

  let interrupted = null;

  for await (const [mode, data] of stream) {
    if (mode === "messages") {
      const [chunk, metadata] = data;
      // Output only tokens from the final answer (filter model calls inside tools)
      if (chunk.content && typeof chunk.content === "string") {
        process.stdout.write(chunk.content);
      }
    } else if (mode === "custom") {
      console.log(`\n  ⚙️ [progress] ${data.message}`);
    }
  }

  // Check whether an interrupt happened: read the task's interrupt info from the latest state snapshot
  const state = await agent.getState(config);
  if (state.tasks.length > 0 && state.tasks[0].interrupts?.length > 0) {
    interrupted = state.tasks[0].interrupts[0].value;
  }
  return interrupted;
}

// ===== 5. Run the whole flow =====
const THREAD = "trip-2026";

// --- Turn 1: look things up (streaming typewriter output) ---
console.log("👤 User: Check the weather in Sanya for me, and recommend a hotel");
console.log("🤖 Concierge: ");
const interruptPayload = await chat(THREAD, "Check the weather in Sanya for me, and recommend a hotel");

// --- Turn 2: place the order (this triggers human confirmation) ---
if (!interruptPayload) {
  console.log("\n\n👤 User: Book Seaview Bay Hotel for 3 nights");
  console.log("🤖 Concierge: ");
  const payload = await chat(THREAD, "Book Seaview Bay Hotel for 3 nights");

  if (payload) {
    // ===== The graph paused and is waiting for human confirmation =====
    console.log("\n\n⏸️ Confirmation needed:", JSON.stringify(payload, null, 2));

    // In a real app: show a dialog or message here and wait for a click
    const userSaysYes = true;  // simulate the user clicking "Confirm"

    console.log(`\n👤 User: ${userSaysYes ? "Confirm the booking" : "Cancel the booking"}`);
    console.log("🤖 Concierge: ");
    await resume(THREAD, { approved: userSaysYes });
  }
}

// Wrapper for resuming execution
async function resume(threadId, resumeValue) {
  const config = { configurable: { thread_id: threadId } };

  const stream = await agent.stream(
    new Command({ resume: resumeValue }),   // ★ the resume input
    { streamMode: ["messages", "custom"], ...config }
  );

  for await (const [mode, data] of stream) {
    if (mode === "messages") {
      const [chunk] = data;
      if (chunk.content && typeof chunk.content === "string") {
        process.stdout.write(chunk.content);
      }
    }
  }
}
```

> 💡 **Note:** When `streamMode` is an array, `config` (including `configurable`) has to sit in the second argument together with the mode — that is why the code above spreads `{ streamMode: [...], ...config }`.

### Every Idea from the Tutorial Is Hiding in This Project

| What you see | The LangGraph mechanism behind it |
|--------------|-----------------------------------|
| `⚙️ [progress]` popping up live | `config.writer` + the `custom` stream mode |
| The answer appearing word by word | the `messages` stream mode |
| Turn 2 still remembers the Sanya context | `MemorySaver` + `thread_id` |
| The order pauses and waits for confirmation | `interrupt` inside the tool + a checkpoint |
| After "Confirm the booking," the run finishes | `new Command({ resume })` |

## 🚀 Next Steps (homework for you)

1. **Add time-travel debugging:** use `getStateHistory` to print the agent's state at every step and see what it was thinking
2. **Switch persistence:** replace `MemorySaver` with a SQLite checkpointer so memory survives a process restart
3. **Add long-term memory:** use `InMemoryStore` (Chapter 26) to remember the user's travel preferences and recommend them on the next conversation
4. **Split into experts:** split "check the weather" and "book a hotel" into two sub-agents and team them up with `createSupervisor` (Chapter 24)
5. **Connect a frontend:** push the three kinds of `stream` data (tokens, progress, and interrupt requests) to a web page over WebSocket and build a real chat UI
