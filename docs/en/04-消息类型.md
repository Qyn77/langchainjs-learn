# 04-Message Types: HumanMessage/SystemMessage

> 💡 **Note:** This tutorial is for LangChain.js v1.x and requires Node.js 20+

## 🎯 Chapter Goals

- ✅ Understand the message format used by large models
- ✅ Learn the three common message types
- ✅ Learn how to build a multi-turn conversation

---

## 📦 Three Common Message Types

### 1. HumanMessage - User Message

This is the **user's input**:

```javascript
import { HumanMessage } from "@langchain/core/messages";

const userMessage = new HumanMessage("Hello, please write a poem for me");
```

### 2. SystemMessage - System Message

This is a **system instruction** that sets the AI's role and behavior:

```javascript
import { SystemMessage } from "@langchain/core/messages";

const systemMsg = new SystemMessage("You are a professional translation assistant. You only translate and do not answer other questions.");
```

### 3. AIMessage - AI Message

This is the **AI's reply** (usually used in conversation history):

```javascript
import { AIMessage } from "@langchain/core/messages";

const aiMessage = new AIMessage("Hello! I am your AI assistant.");
```

---

## 💡 Complete Example

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage, AIMessage } from "@langchain/core/messages";

const model = new ChatOpenAI({
  model: "MiniMax/MiniMax-M2.5",
  apiKey: process.env.MODELSCOPE_API_KEY,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});

// Example 1: user message only
const response1 = await model.invoke([
  new HumanMessage("Hello!")
]);

// Example 2: system message + user message
const response2 = await model.invoke([
  new SystemMessage("You are a catgirl. End every sentence with 'meow~'"),
  new HumanMessage("Introduce yourself")
]);

// Example 3: multi-turn conversation
const response3 = await model.invoke([
  new HumanMessage("I like apples"),
  new AIMessage("Apples are a very healthy fruit!"),
  new HumanMessage("Why?")
]);
```

---

## 📋 Comparing Message Types

| Message type | Purpose | When to use | Example |
|----------|------|----------|------|
| `SystemMessage` | Set system behavior | Role setup and rule constraints | "You are a translation assistant" |
| `HumanMessage` | User input | Questions and instructions | "Please write a poem for me" |
| `AIMessage` | AI reply | Conversation history and context | "Sure, I'll write a poem" |

---

## 🔄 Multi-turn Conversation Example

```javascript
const messages = [
  // Turn 1
  new HumanMessage("I want to learn programming"),
  new AIMessage("Great! Which programming language do you want to learn?"),
  
  // Turn 2
  new HumanMessage("Python"),
  new AIMessage("Python is a great choice! Do you have any programming background?"),
  
  // Turn 3
  new HumanMessage("None at all"),
];

const response = await model.invoke(messages);
```

## ⚙️ AIMessage Parameters in Detail

```javascript
const aiMessage = new AIMessage(content, kwargs);

// Parameters:
// - content: string - message content
// - kwargs: object - extra parameters

// Example
const msg = new AIMessage("Hello", {
  name: "assistant",  // optional: the AI's name
  // other metadata...
});
```

## ⚠️ Notes

### 1. Where to Put SystemMessage

Put SystemMessage at the **start of the message list**:

```javascript
// ✅ Correct
const messages = [
  new SystemMessage("You are an assistant"),
  new HumanMessage("Hello"),
];

// ❌ Not recommended
const messages = [
  new HumanMessage("Hello"),
  new SystemMessage("You are an assistant"),  // may be ignored
];
```

### 2. Message Objects vs Plain Objects

LangChain v1.x also supports a plain-object format:

```javascript
// LangChain message objects (recommended)
const response = await model.invoke([
  new HumanMessage("Hello")
]);

// Plain object format (also supported)
const response = await model.invoke([
  { role: "user", content: "Hello" }
]);
```

---

## 📝 Chapter Summary

- `HumanMessage` = what the user says
- `SystemMessage` = instructions for the AI (put them first)
- `AIMessage` = what the AI says (for conversation history)
- Multi-turn conversations must keep the earlier messages
