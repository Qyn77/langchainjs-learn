## 📦 What Is ChatOpenAI?

`ChatOpenAI` is LangChain's **chat model class**. It supports every API that is compatible with OpenAI.

Supported model platforms:
- OpenAI (GPT-4, GPT-3.5)
- ModelScope (the Modelers community)
- Azure OpenAI
- Other APIs compatible with the OpenAI format

---

## 🔧 Basic Usage

### 1. Import the Class

```javascript
import { ChatOpenAI } from "@langchain/openai";
// Or CommonJS
const { ChatOpenAI } = require("@langchain/openai");
```

### 2. Create a Model Instance

```javascript
const model = new ChatOpenAI({
  model: "MiniMax/MiniMax-M2.5",
  apiKey: "your API key",
  temperature: 0.7,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});
```

### 3. Call the Model

```javascript
import { HumanMessage } from "@langchain/core/messages";

// Option 1: invoke() - get the full reply at once
const response = await model.invoke([
  new HumanMessage("Hello, please introduce Beijing")
]);
console.log(response.content);

// Option 2: stream() - get the reply as a stream
const stream = await model.stream(messages);
for await (const chunk of stream) {
  process.stdout.write(chunk.content);
}
```

## ⚙️ All Parameters in Detail

### Constructor Parameters

| Parameter | Type | Default | Description |
|------|------|--------|------|
| `model` | string | - | **Model name**, such as `gpt-4` or `MiniMax/MiniMax-M2.5` |
| `apiKey` | string | - | **API key**. You can also provide it with the `OPENAI_API_KEY` environment variable |
| `organization` | string | - | OpenAI organization ID |
| `configuration` | object | - | OpenAI client configuration |
| `configuration.baseURL` | string | `https://api.openai.com/v1` | API base URL |
| `configuration.timeout` | number | `60000` | Timeout (milliseconds) |
| `configuration.httpAgent` | Agent | - | HTTP proxy |
| `configuration.headers` | object | - | Custom request headers |
| `temperature` | number | `0.7` | **Temperature**, controls randomness (0-2) |
| `maxTokens` | number | - | Maximum number of output tokens |
| `topP` | number | `1` | Nucleus sampling parameter (0-1) |
| `frequencyPenalty` | number | `0` | Frequency penalty (-2 to 2) |
| `presencePenalty` | number | `0` | Presence penalty (-2 to 2) |
| `n` | number | `1` | How many completions to generate |
| `logitBias` | object | - | Adjust the probability of specific tokens |
| `stop` | string\|array | - | Stop sequences |
| `streaming` | boolean | `false` | Whether to stream the output (note: the `stream()` method is recommended) |
| `modelKwargs` | object | - | Extra parameters passed through to the model |

## 🌡️ The Temperature Parameter in Detail

```javascript
// Low temperature (0.0-0.3) - more certain, conservative, and predictable
const conservative = new ChatOpenAI({
  temperature: 0.1,
  // Good for: factual Q&A, code generation, data extraction
});

// Medium temperature (0.5-0.8) - balanced
const balanced = new ChatOpenAI({
  temperature: 0.7,  // default
  // Good for: general conversation, creative writing
});

// High temperature (1.0-2.0) - more creative and random
const creative = new ChatOpenAI({
  temperature: 1.5,
  // Good for: brainstorming, writing poetry
});
```

## 📋 Complete Sample Code

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

async function main() {
  // Create the model
  const model = new ChatOpenAI({
    // Required parameters
    model: "MiniMax/MiniMax-M2.5",
    apiKey: process.env.MODELSCOPE_API_KEY || "your API key",
    
    // Optional parameters
    temperature: 0.7,        // creativity
    maxTokens: 1024,         // maximum output length
    topP: 1,                 // nucleus sampling
    frequencyPenalty: 0,     // frequency penalty
    presencePenalty: 0,      // presence penalty
    
    // API configuration
    configuration: {
      baseURL: "https://api-inference.modelscope.cn/v1",
      timeout: 60000,        // 60-second timeout
    },
  });

  // Build the messages
  const messages = [
    new SystemMessage("You are a professional translation assistant."),
    new HumanMessage("Please translate the following English into Chinese: Hello, World!"),
  ];

  // Call the model
  const response = await model.invoke(messages);
  
  console.log("Translation:", response.content);
}

main();
```

## 🔄 invoke() vs stream()

| Method | Return value | Use case | Example |
|------|--------|----------|------|
| `invoke()` | `AIMessage` | Short text, when you need the complete result | `const res = await model.invoke(msg)` |
| `stream()` | `AsyncIterable` | Long text, real-time display | `for await (const c of await model.stream(msg))` |

```javascript
// invoke() example
const response = await model.invoke([
  new HumanMessage("Hello")
]);
console.log(response.content);  // Print everything at once after it finishes

// stream() example
const stream = await model.stream([
  new HumanMessage("Please write a long article")
]);
for await (const chunk of stream) {
  process.stdout.write(chunk.content);  // Print piece by piece
}
```

## ⚠️ Common Issues

### 1. Invalid API Key

```
Error: 401 Unauthorized
```

Fix: Check that the API key is correct and that you have available quota.

### 2. Model Does Not Exist

```
Error: 404 Model not found
```

Fix: Check that `model` is correct. Model names differ across platforms.

### 3. Timeout

```
Error: Request timeout
```

Fix: Increase `configuration.timeout`, or check your network connection.

### 4. Insufficient Quota

```
Error: 429 InsufficientQuotaError
```

Fix: Add credits, or switch to another model.

## 📝 Chapter Summary

- `ChatOpenAI` is the main class for calling large models
- `invoke()` gets the reply all at once; `stream()` streams it
- `temperature` controls how random the output is
- `configuration.baseURL` sets the API endpoint
- The response object includes `content`, `tokenUsage`, and other information
