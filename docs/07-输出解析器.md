# 07-输出解析器：结构化输出

> 💡 **注意：** 本教程使用 Zod v4 (`zod@^4.3.6`)，基础用法与 v3 相同

## 🎯 本章目标

- ✅ 掌握**推荐方式**：`withStructuredOutput()` 直接得到结构化对象
- ✅ 了解兜底方式：手动解析 JSON + Zod 验证
- ✅ 学会根据场景选择合适的结构化输出方案

---

## 🤔 为什么需要输出解析器？

### 没有解析器时

```javascript
const response = await model.invoke([
  new HumanMessage("请返回一个 JSON，包含姓名和年龄")
]);

console.log(response.content);
// 输出：{
//   "name": "小明",
//   "age": 25
// }

// ❌ 问题：这是字符串，不是真正的对象！
// 需要手动 JSON.parse()，还可能解析失败
```

### 使用结构化输出后

LangChain 提供两种结构化输出方式：

```javascript
// ✅ 方式一（推荐）：withStructuredOutput —— 直接得到验证后的对象
const structuredModel = model.withStructuredOutput(schema);
const result = await structuredModel.invoke("请提取人物信息");
// result 已经是 { name: "张三", age: 28, ... }，无需手动解析！

// 🔧 方式二（兜底）：手动解析 + Zod 验证
const parsed = schema.parse(JSON.parse(response.content));
```

| 对比 | 方式一：`withStructuredOutput` | 方式二：手动解析 |
|------|------------------------------|----------------|
| 原理 | 底层用**工具调用**强制模型按 schema 输出 | Prompt 约定 + 正则提取 + JSON.parse |
| 可靠性 | 高（schema 约束由框架保证） | 一般（模型可能输出多余文字导致解析失败） |
| 适用 | 模型支持工具调用时（绝大多数现代模型） | 模型不支持工具调用的极端场景 |
| 要求 | 传入 Zod / JSON Schema | 自己写提取和容错逻辑 |

## 🚀 方式一（推荐）：withStructuredOutput

`withStructuredOutput()` 是 LangChain v1.x 模型层结构化输出的标准做法：传入一个 Zod Schema，返回一个"结构化版模型"，调用它直接得到**解析并验证好的对象**。

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";
import { z } from "zod";

const model = new ChatOpenAI({
  model: "MiniMax/MiniMax-M2.5",
  apiKey: process.env.MODELSCOPE_API_KEY,
  temperature: 0,
  configuration: {
    baseURL: "https://api-inference.modelscope.cn/v1",
  },
});

// 步骤 1：定义 Zod Schema（describe 会帮助模型理解字段含义）
const personSchema = z.object({
  name: z.string().describe("人物姓名"),
  age: z.number().describe("年龄"),
  occupation: z.string().describe("职业"),
});

// 步骤 2：绑定结构化输出
const structuredModel = model.withStructuredOutput(personSchema);

// 步骤 3：调用 —— 直接得到对象，不需要 JSON.parse！
const result = await structuredModel.invoke([
  new HumanMessage("张三今年 28 岁，是一名软件工程师"),
]);

console.log(result);
// { name: "张三", age: 28, occupation: "软件工程师" }
console.log(typeof result.age);  // number —— 类型都对
```

### 它是怎么工作的？

`withStructuredOutput` 底层把你传入的 schema 转换成一个**工具定义**，通过工具调用机制强制模型按结构返回，再自动解析验证。所以：

- ✅ 不用再写"请只返回 JSON"之类的提示词
- ✅ 不用正则提取、不用担心模型多说一句话导致解析失败
- ✅ 输出自动通过 schema 验证，类型可靠

### 常用选项

```javascript
// 想同时拿到原始消息和解析结果：
const structuredModel = model.withStructuredOutput(personSchema, {
  includeRaw: true,
});
const { raw, parsed } = await structuredModel.invoke("...");
```

> 💡 **前置条件：** 模型需要支持工具调用（绝大多数现代模型都支持，本教程的 MiniMax-M2.5 支持）。如果模型不支持工具调用，就用下面的方式二手动解析。
>
> 💡 **Agent 场景：** 如果你用的是第 12 章的 `createAgent`，可以直接传 `responseFormat` 参数获得结构化输出（结果在 `result.structuredResponse`），详见官方文档 [Structured output](https://docs.langchain.com/oss/javascript/langchain/structured-output)。

## 🔧 方式二（兜底）：手动解析 JSON + Zod

当模型不支持工具调用，或你想完全掌控解析过程时，用"Prompt 约定 + 手动解析 + Zod 验证"：

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";
import { z } from "zod";

async function main() {
  const model = new ChatOpenAI({
    model: "MiniMax/MiniMax-M2.5",
    apiKey: process.env.MODELSCOPE_API_KEY,
    temperature: 0,  // 结构化输出时建议用 0
    configuration: {
      baseURL: "https://api-inference.modelscope.cn/v1",
    },
  });

  // 步骤 1：定义输出模式（Zod Schema）
  const personSchema = z.object({
    name: z.string().describe("人物姓名"),
    age: z.number().describe("年龄"),
    occupation: z.string().describe("职业")
  });

  // 步骤 2：创建 Prompt，指示模型返回 JSON
  const messages = [
    new SystemMessage("你是一个数据提取助手。请从文本中提取信息，并只返回 JSON 格式，不要其他内容。"),
    new HumanMessage(`
从以下文本中提取人物信息，返回 JSON 格式：
{
  "name": "姓名",
  "age": 年龄（数字）,
  "occupation": "职业"
}

文本：张三今年 28 岁，是一名软件工程师
`)
  ];

  // 步骤 3：调用模型
  const response = await model.invoke(messages);
  console.log("AI 原始回复:", response.content);

  // 步骤 4：手动解析 JSON
  try {
    // 提取 JSON 部分（可能包含在代码块中）
    const jsonMatch = response.content.match(/\{[\s\S]*\}/);
    const jsonStr = jsonMatch ? jsonMatch[0] : response.content;
    const result = JSON.parse(jsonStr);
    
    // 步骤 5：使用 Zod 验证
    const validated = personSchema.parse(result);
    
    console.log("\n✅ 解析成功!");
    console.log("姓名:", validated.name);
    console.log("年龄:", validated.age);
    console.log("职业:", validated.occupation);
  } catch (e) {
    console.error("解析失败:", e.message);
  }
}

main();
```

## 📋 Zod 常用类型

| Zod 类型 | 说明 | 示例 |
|----------|------|------|
| `z.string()` | 字符串 | `z.string().email()` |
| `z.number()` | 数字 | `z.number().min(0).max(100)` |
| `z.boolean()` | 布尔值 | `z.boolean()` |
| `z.array()` | 数组 | `z.array(z.string())` |
| `z.enum()` | 枚举 | `z.enum(["positive", "negative", "neutral"])` |
| `z.object()` | 对象 | `z.object({ name: z.string() })` |
| `z.optional()` | 可选 | `z.string().optional()` |
| `z.null()` | 可为空 | `z.string().null()` |

## 🔧 链式调用（手动解析版）

```javascript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";
import { PromptTemplate } from "@langchain/core/prompts";
import { z } from "zod";

async function main() {
  const model = new ChatOpenAI({
    model: "MiniMax/MiniMax-M2.5",
    apiKey: process.env.MODELSCOPE_API_KEY,
    temperature: 0,
    configuration: {
      baseURL: "https://api-inference.modelscope.cn/v1",
    },
  });

  // 定义 Schema
  const schema = z.object({
    term: z.string(),
    definition: z.string(),
    example: z.string()
  });

  // 创建 Prompt
  const prompt = PromptTemplate.fromTemplate(
    "请用 JSON 格式解释什么是{topic}，包含 term、definition、example 三个字段。只返回 JSON，不要其他内容。"
  );

  // 创建链：Prompt → Model
  const chain = prompt.pipe(model);

  // 调用
  const response = await chain.invoke({ topic: "机器学习" });
  
  // 手动解析
  const jsonMatch = response.content.match(/\{[\s\S]*\}/);
  const jsonStr = jsonMatch ? jsonMatch[0] : response.content;
  const result = schema.parse(JSON.parse(jsonStr));
  
  console.log("术语:", result.term);
  console.log("定义:", result.definition);
  console.log("例子:", result.example);
}

main();
```

## ⚠️ 注意事项

### 1. Temperature 设为 0

结构化输出需要确定性：

```javascript
const model = new ChatOpenAI({
  temperature: 0,  // ✅ 推荐
  // ...
});
```

### 2. 明确指示返回 JSON

```javascript
// ✅ 好的 Prompt
new SystemMessage("只返回 JSON 格式，不要其他内容。")

// ❌ 不好的 Prompt
new SystemMessage("请分析一下...")  // 模型可能返回多余的文字
```

### 3. 处理解析错误

```javascript
try {
  const jsonMatch = response.content.match(/\{[\s\S]*\}/);
  const result = JSON.parse(jsonMatch[0]);
  const validated = schema.parse(result);
} catch (e) {
  console.error("解析失败:", e.message);
  // 可以重试或返回默认值
}
```

### 4. 处理代码块

模型可能返回 Markdown 代码块：

```javascript
// 回复可能是：```json {...} ```
const jsonStr = response.content
  .replace(/```json\s*/g, '')
  .replace(/```\s*/g, '')
  .trim();
```

## 📊 完整工具函数

```javascript
import { z } from "zod";

/**
 * 解析并验证 AI 返回的 JSON
 * @param {string} content - AI 的原始回复
 * @param {z.ZodSchema} schema - Zod 验证模式
 * @returns {object} 验证后的对象
 */
function parseStructuredOutput(content, schema) {
  try {
    // 1. 提取 JSON 部分
    const jsonMatch = content.match(/\{[\s\S]*\}/);
    if (!jsonMatch) {
      throw new Error("未找到 JSON 内容");
    }
    
    // 2. 清理 Markdown 代码块
    let jsonStr = jsonMatch[0]
      .replace(/```json\s*/g, '')
      .replace(/```\s*/g, '')
      .trim();
    
    // 3. 解析 JSON
    const parsed = JSON.parse(jsonStr);
    
    // 4. Zod 验证
    return schema.parse(parsed);
  } catch (e) {
    console.error("解析失败:", e.message);
    throw e;
  }
}

// 使用
const result = parseStructuredOutput(response.content, personSchema);
```

## 📝 本章小结

- **首选 `withStructuredOutput(schema)`**：底层用工具调用保证输出符合 schema，直接得到验证后的对象
- 手动解析（Prompt 约定 JSON + 提取 + Zod 验证）是模型不支持工具调用时的兜底方案
- 手动解析时用 `SystemMessage` 指示模型返回 JSON，`temperature` 设为 0 提高确定性
- Zod 用于验证和类型安全（详见第 11 章）
- Agent 场景可用 `createAgent` 的 `responseFormat` 参数（结果在 `structuredResponse`）
